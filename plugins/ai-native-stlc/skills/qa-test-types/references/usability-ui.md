# UI and usability

**Goal:** screens match the design and behave consistently.
**Oracle:** the design (Figma/mockups) and design cards; consistency between screens of the same app.

## Checklist
- Layout against the design at the agreed viewport sizes; text not clipped or overlapping.
- Labels, buttons and messages use the card wording; the same action has the same name everywhere.
- States: empty, loading, error, long text, many rows, disabled controls.
- Feedback: every action shows a result; destructive actions ask for confirmation.
- Keyboard: Tab order follows the visual order (also part of accessibility).

## Tools
Screenshot only the screen under review at a fixed viewport; compare with the design image.

## Evidence
The screenshot next to the design reference.

## Not a bug
Personal taste. A difference from the design is a bug only when the design is approved and
named in the plan; otherwise it is a question.
