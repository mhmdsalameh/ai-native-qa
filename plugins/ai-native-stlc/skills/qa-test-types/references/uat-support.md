# UAT support

**Goal:** help the client's users run acceptance tests and turn their feedback into valid items.
**Oracle:** the client's acceptance criteria (as cards) - not the tester's opinion.

## Checklist
- Prepare UAT scripts from P1 cases in plain business language (no technical steps).
- Prepare test accounts and data per role; confirm the UAT environment is ready (smoke first).
- Triage client feedback: bug (through the gate), change request (not in the cards), question,
  or training issue. Change requests go to the PM, not to ADO as bugs.

## Evidence
The client's screenshots and notes, saved under `evidence/uat/`.

## Not a bug
A request for behaviour no card describes (change request).
