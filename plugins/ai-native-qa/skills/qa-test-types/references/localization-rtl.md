# Localization, Arabic and right-to-left

**Goal:** the app works and reads correctly in each supported language.
**Oracle:** language cards, the approved glossary (`notes/glossary.md`), and RTL layout rules.

## Checklist
- Every screen in each language: no untranslated strings, no mixed-language labels.
- RTL: layout mirrored (navigation, icons with direction, progress), text right-aligned,
  numbers and Latin product names still read left to right inside Arabic text.
- Input: Arabic letters, Arabic-Indic digits (٠-٩) and Latin digits where the card allows them;
  search finds Arabic with and without diacritics when the card says so.
- Formats: dates (Gregorian/Hijri if specified), currency symbol and position, thousands separator.
- Truncation: Arabic strings are often longer or shorter; check buttons and table headers.
- Documents and emails generated by the app in each language.

## Tools
Switch language in the app and repeat the P1 flows; screenshot each changed screen once.

## Evidence
Screenshot pairs (EN/AR) of the same screen.

## Not a bug
A translation you would phrase differently: send it to the glossary owner as a question,
unless the glossary already fixes the term.
